# Weather scene photo credits

Home's per-condition backgrounds (`scene_*.rgb565`, generated by
`tools/gen_weather_scenes.py`) are real photographs, center-cropped to
480x320 and converted to raw RGB565 - not illustrated or drawn. All eight
are from Wikimedia Commons; the source URL, author and license below are
also recorded in `tools/gen_weather_scenes.py`'s `SCENES` table, which is
the source of truth if this file and that script ever drift apart.
